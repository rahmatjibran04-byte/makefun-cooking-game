Kuali Emas — a complete Indonesian street-food cooking game in vanilla JavaScript: take orders from the board, chop, cook, assemble and serve six recipes before the 3-minute shift ends, with combos, tips and burnt food.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network, just static files under game/.
